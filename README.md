# AI Interview Preparation Platform

An AI-powered interview preparation platform that generates personalized interview questions, evaluates responses, and provides feedback using machine learning and LLMs.

## Tech Stack
- Frontend: Next.js
- Backend: FastAPI
- Database: PostgreSQL
- AI/ML: OpenAI API, NLP
- Cloud: AWS/GCP

## Features
- Resume upload
- AI-generated interview questions
- Personalized feedback
- Interview analytics
- User dashboard

Currently under development.
